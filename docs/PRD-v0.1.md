## 1. 背景与目标

### 1.1 问题

亚马逊卖家在 Sponsored Products 上的月预算中，约 15%–35% 可能花在「有点击、0 订单」的搜索词上。多数运营很少导出 Search Term Report（STR），否词表偏薄，ACOS 恶化后才被动止血。全托管 PPC 常见报价 $500–$1,500+/月，对「只想先洗搜索词、导出否词」的卖家过重。

### 1.2 产品一句话

卖家上传 Search Term Report CSV → 算出广告浪费金额 → 导出可导入的否词表。

### 1.3 目标（2–4 周 MVP）

- 上线可自助：上传 STR → 浪费金额洞察 → 否词 CSV 导出 → 订阅付费。
- 约束：CSV 优先，首版不接 Amazon Ads API；不做全托管 PPC；不保证 ACOS；中文友好 + 出海美元定价。

### 1.4 ICP

| 做 | 不做 |
|---|---|
| 北美/欧站卖家运营或老板（1–20 人） | 月广告花费 &lt; $800 |
| SP 月花费约 $1,500–$30,000 | 保证 ACOS / 全托管 |
| 症状：ACOS 变差、少导出 STR、否词薄、先止血不愿托管 | 无亚马逊广告业务；灰产 |

### 1.5 竞品缝隙

卡在「工具免费档」与「全托管 PPC」之间：只做搜索词清洗 + 否词导出。旧人工 L0–L3 报价仅作漏斗参考，主路径为免费快检 → $29/月订阅；人工诊断可为可选加购，不做主路径。

## 2. 用户故事

1. **作为**北美/欧站 SP 卖家运营，**我想**上传 STR CSV 并立刻看到「浪费金额」摘要，**以便**判断是否值得继续用工具止血。
2. **作为**未登录访客，**我想**对一份小文件做 1 次快检，**以便**零门槛验证产品价值后再注册。
3. **作为**已注册免费用户，**我想**每月做 1 次完整分析并看到推荐否词列表，**以便**形成使用习惯并评估是否升级。
4. **作为**付费订阅用户，**我想**导出以 Keyword Text + Match Type（Negative Exact）为主、可选含 Campaign Name 的否词 CSV，**以便**直接导入 Seller Central / Ads 后台。
5. **作为**多站点卖家（付费），**我想**在订阅期内多次上传不同站点/不同周期的 STR，**以便**持续清洗而非一次性。
6. **作为**老板或运营负责人，**我想**看到「高花费 + 足够点击 + 0 单 → 建议 Negative Exact」等可解释规则，**以便**信任结果并内部对齐动作。
7. **作为**中文用户，**我想**界面与说明为中文、定价以美元结算，**以便**出海卖家团队无障碍使用。

## 3. 核心流程（恰好 3 步）

### 步骤 1：上传 STR CSV

- 用户选择 Amazon Search Term Report 导出的 CSV（首版仅 CSV，不接 Ads API）。
- 系统校验：编码、必要列（至少含 search term / 花费 / 点击 / 订单或等价字段；列名需做常见别名映射）、文件大小与行数上限（按档位）。
- 未登录：仅允许「小文件」快检（阈值见 §5，研发按字节或行数实现）。
- 已登录免费：每月 1 次完整分析额度。
- 付费：$29/月额度内可多次完整分析（具体上限见 §5）。

### 步骤 2：计算浪费金额与否词建议

- **浪费金额**：汇总「0 订单且有花费」的搜索词花费（及可选：占总花费占比）。
- **否词候选规则（MVP 默认，可配置阈值）**：高花费 + 足够点击 + 0 订单 → 建议 **Negative Exact**。
- **健康出单词**：有订单的词 → 标记为观察/可考虑提成精准（MVP 可只展示，不做自动加词导出）。
- 输出：浪费金额摘要、候选否词数量、Top 浪费词列表（免费/付费展示深度不同，见 §5）。

### 步骤 3：导出可导入否词表

- 付费用户可导出完整否词 CSV，字段约定（已拍板）：
  - **必选**：`Keyword Text`、`Match Type`（值为 negative exact / Negative Exact，实现时与后台导入模板对齐并在 UI 注明）。
  - **可选列**：`Campaign Name`（用户勾选是否带上；若 STR/映射能关联到 Campaign 则填充，否则留空或略过该行策略需在实现中明确）。
- 免费层：未登录快检与注册免费完整分析均可看摘要与部分列表；**完整可导入否词 CSV 仅付费开放**（免费可导出受限版：如 Top N 或加水印说明「不可直接导入完整表」，见 §5）。

## 4. MVP 范围 / 明确不做

### 4.1 MVP 做（In Scope）

- STR CSV 上传、解析、列名别名兼容（北美/欧站常见英文表头优先；中文表头若常见则一并映射）。
- 浪费金额计算与可视化摘要（数字 + 占比即可，不做复杂 BI）。
- 否词推荐（Negative Exact 为主）+ 付费完整 CSV 导出（字段见上）。
- 账号：访客快检 → 注册/登录 → 订阅（Stripe 或等价美元收款）。
- 中文 UI；定价与账单以 USD 展示。
- 基础用量限制：未登录 1 次小文件；注册免费每月 1 次完整分析；付费多次（§5）。

### 4.2 明确不做（Out of Scope，首版）

- Amazon Ads API 对接、自动拉取报告。
- 全托管 PPC、代投放、保证 ACOS。
- 自动创建/推送否词到广告账户（仅导出 CSV，用户自行导入）。
- 多匹配类型策略引擎（Phrase/Broad 否词、复杂规则工厂）——MVP 固定 Exact。
- 灰产、无广告卖家场景。
- 人工诊断作为主转化路径（可选加购可后置，不阻塞 MVP）。

## 5. 定价与转化漏斗

> 以下为 **CEO 已拍板（2026-10-17）**，产品主路径按此实现。

### 5.1 档位

| 档位 | 价格 | 权益 |
|---|---|---|
| **访客快检** | $0（未登录） | 小文件 **1 次**快检；展示浪费金额摘要 + 有限 Top 词；**不可**导出完整可导入否词表 |
| **Free（注册）** | $0 | **每月 1 次**完整分析；摘要 + 更完整列表预览；导出受限（如 Top N 或带「非完整导入」水印/截断） |
| **Paid** | **$29/月**（单档，不做 $79） | 完整可导入否词 CSV（Keyword Text + Match Type；可选 Campaign Name）；订阅期内多次完整分析（建议上限：如 30 次/月或按合理防刷，实现时定）；保留近期分析历史（建议至少最近 N 次） |

说明：原讨论区间 $29–$79 **已改为单档 $29/月**；不做 Pro/$79 档。

### 5.2 「小文件」建议阈值（实现用，可微调）

- 建议：行数 ≤ 2,000 **或** 文件 ≤ 1 MB（取先触发者）；超出引导注册/付费后再跑完整分析。
- 完整分析：建议支持至少常见 STR 规模（如数万行级），具体上限与超时策略由研发在 4 周内定可接受默认值。

### 5.3 转化漏斗

```
未登录小文件快检（浪费金额 wow）
  → 注册领「每月 1 次完整分析」
    → 看到完整列表但导出受限
      → 订阅 $29/月解锁完整可导入 CSV + 多次分析
```

人工诊断：漏斗外可选加购，不写入 MVP 主路径 KPI。

## 6. 成功指标

| 类别 | 指标 | 可测定义 | 4 周目标假设 |
|---|---|---|---|
| 激活 | 快检完成率 | 进入上传页且成功出浪费金额摘要的会话占比 | ≥ 40% |
| 激活 | 注册转化 | 完成至少 1 次快检的访客中完成注册的比例 | ≥ 15% |
| 转化 | 付费转化 | 注册用户中在 14 日内订阅 $29 的比例 | ≥ 5% |
| 价值证明 | 人均展示浪费金额 | 有结果会话的浪费金额中位数（USD） | 中位数 ≥ $200（用于文案与售卖，非承诺节省） |
| 留存 | D7 回访/再分析 | 付费用户中 7 日内再次上传或打开历史的比例 | ≥ 30% |
| 留存 | 付费续费意向代理 | 首月取消率（若已开订阅） | 首月取消 &lt; 40%（样本小时仅作方向） |

埋点最低集：上传成功/失败、分析完成、注册、导出点击（受限 vs 完整）、订阅开始/取消。

## 附录 A：规则逻辑（研发可拆任务）

- 输入行：search_term, spend, clicks, orders（及可选 campaign）。
- 浪费：`orders == 0 && spend > 0` 的 spend 求和。
- 否词候选：`orders == 0 && clicks >= C_min && spend >= S_min` → Keyword Text = search_term，Match Type = Negative Exact。
- `C_min` / `S_min`：MVP 给保守默认（如 clicks ≥ 7–10，spend ≥ $5–$10），产品可后续做成简单滑杆；首版写死默认并在 UI 展示规则说明即可。
